# WebLens Citation and Provenance Specification

## 1. Rationale & Core Principles

In an autonomous agent workflow, unverified citations produce catastrophic failures: agents cite dead links, hallucinated URLs, or misattributed facts.

WebLens enforces cryptographic, verifiable provenance for every fact returned by the system. A downstream agent receiving a WebLens citation can independently verify that:
1. The cited document existed at the specified URL at the fetch timestamp.
2. The byte content of the document has not mutated (cryptographic SHA-256 seal).
3. The cited sentence or statistic appears verbatim at the exact character offsets recorded.

---

## 2. Citation Schema Specification

Every citation generated by WebLens follows this JSON schema:

```json
{
  "citation_id": "cite-f8b1a2c4",
  "url": "https://example.org/article",
  "canonical_url": "https://example.org/article",
  "title": "Document Title",
  "domain": "example.org",
  "fetch_timestamp": "2026-11-02T17:30:00Z",
  "http_status": 200,
  "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "verbatim_span": {
    "text": "Exact sentence extracted from source text.",
    "char_start": 1420,
    "char_end": 1464,
    "token_count": 8
  },
  "authority_tier": 2,
  "cached": false
}
```

## 3. Provenance Mechanisms

### 3.1 URL Canonicalization
URLs are normalized before hashing, fetching, or recording:
- Scheme normalized to lowercase (`https`).
- Hostname normalized to lowercase ASCII (`punycode` decoded).
- Standard default ports (`:80`, `:443`) stripped.
- Trailing slashes normalized.
- Tracking query parameters (`utm_*`, `ref`, `fbclid`, `gclid`) stripped.
- Anchor fragments (`#section`) preserved only when pointing to specific DOM targets.

### 3.2 Cryptographic Content Hash
The SHA-256 checksum is calculated over the raw response bytes immediately upon completion of the socket read.
This hash is stored in:
- The local SQLite cache (`weblens.cache`).
- The persistent cryptographic evidence ledger (`evidence/ledger.jsonl`).
- The citation metadata payload returned over MCP.

### 3.3 Verbatim Character Spans
To eliminate hallucinated quotation, WebLens computes exact substring slice indices:
```python
assert raw_extracted_text[char_start:char_end] == verbatim_span_text
```
If the extracted text changes or fails the assertion, the citation is flagged as invalid and excluded from output.

---

## 4. Cryptographic Ledger Chain Integrity

All system evaluations, research traces, and verification runs are immutably logged into `evidence/ledger.jsonl`. Each entry is linked to the previous entry via SHA-256 block hashing:

$$H_i = \text{SHA256}(H_{i-1} \parallel \text{JSON}_{\text{canonical}}(E_i))$$

This hash chain guarantees:
1. Historical runs cannot be retroactively edited, deleted, or fabricated.
2. Every test result and benchmark score is permanently anchored to the exact code commit and raw outputs on disk.
3. Anyone can independently verify ledger integrity by executing `python tools/verify_chain.py`.
