## Interpretation

This is not a clean causal comparison because the rerun changed both the scoring
methodology and the local provider chain. Therefore the result proves **no
improvement**, but does not prove that the Bing-chain change alone caused the
decrease. The local rerun also reached 4,588 ms maximum latency, violating the
2,400 ms hard ceiling.

## Disposition

- Do not mark F2 PASS.
- Do not claim the change improved WebLens.
- Keep the dataset unchanged.
- Next cycle must isolate one retrieval change, use the same scorer for before
  and after, preserve per-item answer evidence, and run twice before KEEP.

## Answer-path fix applied after the rejected measurement

The live chat path was silently discarding real extraction output because the
service emits compact passage text under `x`, while chat only read the fixture
key `p`. The fix now accepts both formats, selects concise query-bearing
sentences, preserves exact spans/fetch timestamps, quarantines injection text,
and returns at most two evidence bullets.

Smoke artifact: `evidence/raw/quality-loop-20261102/chat_smoke_20261102.json`  
SHA-256: `f6c2aa0169e7603e317438bd30e95e177273eb08509a80627d3a81cf9fa1c507`

This improves answer presentation and evidence fidelity, but does **not** yet
constitute a new 100-query F2 score.
